new issue.

新建一条 issue，就是新的一期。不需要服务器，不需要重新部署。

打开 GitHub 新建 Issue 打开仓库

From phone to live.

3 STEPS
1

在 GitHub App 里新建 Issue

打开仓库 daily-read → Issues → New issue。标题写英文标题，正文粘贴下面的模板。

2

把图片直接上传进 Issue

封面和 9 页图文都可以从相册上传；GitHub 会自动生成图片链接。网站会自动把第一张图当作封面，把“9 页图文版”下的图收进画廊。

3

Create issue，网站自动更新

新建即发布。想先存草稿，就给 issue 加一个 draft 标签；网站会忽略它。手机刷新页面即可看到新一期。

BEFORE YOU PUBLISH / 发布前

标题是英文，6–10 个词，最好是一个可被反驳的判断。
正文开头两行 blockquote：第一行中文钩子，第二行日期 · 期号 · 阅读时长 · 来源。
至少一张封面图；9 页图文放在“## 9 页图文版”下面。
“## 词汇”下保留表格，网站会自动生成“加入词书”按钮。
用手机打开网站，确认图片和排版正常；必要时加 draft 修好再发。
